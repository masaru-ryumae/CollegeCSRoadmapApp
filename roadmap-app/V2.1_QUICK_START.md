## Quick Setup

### 1. Install Dependencies
```bash
cd roadmap-app
npm install
```

### 2. Create Supabase Project
- Go to https://supabase.com
- Create new project
- Copy credentials

### 3. Set Environment Variables
```bash
cp .env.example .env.local
# Edit .env.local with your Supabase credentials
```

### 4. Create Database Schema
Run this SQL in Supabase SQL Editor:
```sql
CREATE TABLE user_data (
  id BIGSERIAL PRIMARY KEY,
  user_id UUID UNIQUE NOT NULL REFERENCES auth.users ON DELETE CASCADE,
  favorites JSONB DEFAULT '[]'::jsonb,
  progress JSONB,
  answers JSONB,
  roadmap JSONB,
  last_synced_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

ALTER TABLE user_data ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Users can read their own data"
  ON user_data FOR SELECT
  USING (auth.uid() = user_id);

CREATE POLICY "Users can update their own data"
  ON user_data FOR UPDATE
  USING (auth.uid() = user_id);

CREATE POLICY "Users can insert their own data"
  ON user_data FOR INSERT
  WITH CHECK (auth.uid() = user_id);

CREATE INDEX user_data_user_id_idx ON user_data(user_id);
```

### 5. Configure OAuth (Optional)
In Supabase Dashboard:
1. Go to Authentication > Providers
2. Enable Google and/or GitHub
3. Add your OAuth app credentials
4. Configure redirect URLs

### 6. Test
```bash
npm run dev
# Visit http://localhost:5173
# Try signing up, logging in, cloud sync
```

## Usage Examples

### Use in Components

```typescript
import { useApp } from '../context/AppContext';
import { AuthModal } from '../components/AuthModal';

function MyComponent() {
  const { state, dispatch } = useApp();
  const [authOpen, setAuthOpen] = useState(false);

  const handleAuthSuccess = (user) => {
    dispatch({ type: 'SET_USER', user });
    dispatch({ type: 'SET_AUTHENTICATED', isAuthenticated: true });
  };

  return (
    <>
      <AuthModal 
        isOpen={authOpen}
        onClose={() => setAuthOpen(false)}
        onAuthSuccess={handleAuthSuccess}
      />
      
      {state.isAuthenticated ? (
        <p>Welcome, {state.user?.displayName}</p>
      ) : (
        <button onClick={() => setAuthOpen(true)}>Sign In</button>
      )}
    </>
  );
}
```

### Manage Favorites

```typescript
import { syncFavoritesToCloud } from '../services/cloudSync';

// Add favorite
dispatch({ type: 'ADD_FAVORITE', moduleId: 'module-1' });

// Sync to cloud
if (state.isAuthenticated && state.user) {
  await syncFavoritesToCloud(state.user.id, state.favorites);
}
```

### Export Data

```typescript
import { exportUserData } from '../utils/dataPortability';

// User downloads their data
await exportUserData(userId);
// Creates: cs-roadmap-export-{userId}-{timestamp}.json
```

## Troubleshooting

### "Invalid credentials" error
- Check `VITE_SUPABASE_URL` in `.env.local`
- Verify `VITE_SUPABASE_ANON_KEY` is correct
- Ensure `.env.local` is in `.gitignore`

### OAuth not working
- Verify redirect URLs in Supabase match your app
- Check OAuth app credentials in Google/GitHub
- Clear browser cookies and try again

### Data not syncing
- Check user is authenticated
- Verify network is online
- Check browser console for errors
- Ensure RLS policies are created

### Offline queue not processing
- Reconnect to internet
- Reload the page
- Check `localStorage` for `cs-roadmap-offline-queue`

## Performance Notes

- Initial load initializes Supabase (~100ms)
- Cloud sync happens in background (non-blocking)
- Real-time updates use WebSocket subscriptions
- Offline queue uses localStorage (no network needed)

## Security Notes

1. Never commit `.env.local` (it's in `.gitignore`)
2. Always use HTTPS in production
3. Supabase handles password encryption
4. RLS policies prevent cross-user data access
5. Session tokens auto-managed by Supabase
